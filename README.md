# TR1K Pi companion

A touchscreen companion for the Roland TR-1000 on a Raspberry Pi, over the TR's USB-C port:
clock-synced LFOs, per-step parameter lanes and macros on top of the TR's MIDI CCs, plus the
things MIDI does not reach -- per-track sound and layer selection, mixer routing, reverb, delay
and side chain -- through the TR's own USB editor link.

Python + pygame, no root, no network. Tested on a Pi 4 with a 7" HDMI touchscreen (800x480;
the UI is drawn on a 1024x600 grid and scales to whatever the screen is).

## What you need

- Raspberry Pi (any with a USB host port; Pi 4 used), Raspberry Pi OS, a touchscreen.
- `python3-pygame` (`sudo apt install python3-pygame`, or `pip install -r requirements.txt`).
- The user in the `audio` and `dialout` groups: `sudo usermod -aG audio,dialout $USER`, then log
  out and in. The TR's MIDI arrives on an ALSA raw MIDI device and its editor link is a USB serial
  port; Linux needs no extra driver for either.
- TR-1000 connected over USB-C. On the TR (MENU > SYSTEM > MIDI): Tx Edit Data and Rx Edit Data
  ON, Soft Through OFF (otherwise the TR echoes the companion's own messages back), Tx/Rx Program
  Change ON if you want the panel to follow kit and pattern numbers.

## Run

```sh
git clone <this> ~/tr-companion      # or copy the folder there
~/tr-companion/start.sh              # starts (or restarts) it full screen; log in ~/.cache/tr-companion.log
```

`EXIT APP` is on the SETUP page (Esc with a keyboard). To start it with the desktop, copy
`tr-companion.desktop` to `~/.config/autostart/`. Settings and presets live in
`~/.config/tr-companion/`.

## Pages

- **KIT** -- pick an instrument; see and change the sounds on its Layer A / B (built-in sounds or
  samples, by category), FX route, side-chain depth, pan and sends, the CTRL knobs, the LFOs driving
  it. Double-tap the selected instrument to set its track colour.
- **FX** -- REVERB, DELAY and SIDE CHAIN with their full parameter sets (over the editor link),
  MASTER for the MIDI-only controls (filter, drive, analog FX, master FX, morph, ext in).
- **LFO** -- four LFOs generated by the app (separate from the TR's own): target, shape, sync (NOTE,
  STEP or TIME), rate, depth, centre.
- **LANES** -- four lanes of up to 16 steps of parameter values, with a playhead.
- **MACRO** -- four faders, each driving up to six parameters with its own range and curve.
- **SETUP** -- MIDI channels, send-all, follow-pattern presets, save, playhead style, what a TR
  knob does to automation (floor under it, or pause it), MIDI monitor.
- **LEARN** -- tap a parameter name, change it on the TR, and the address the TR reports is bound
  to it. This is how the FX addresses in `CONTROL-MAP.md` were found.
- **HOLD** (bottom bar) mutes all automation without changing it, for editing on the TR itself.

Values the TR has not reported yet show as `?`; move the knob once, or set it from the panel.

## The control map

[CONTROL-MAP.md](CONTROL-MAP.md) / [control-map.json](control-map.json) list every MIDI CC (from
Roland's MIDI implementation chart) and every USB editor-link address the app uses, with ranges
and option names. `captures/learn-20261108.json` is the LEARN run the FX addresses came from.
